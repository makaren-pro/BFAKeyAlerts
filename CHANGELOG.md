# Changelog

## 1.5.0 - 2026-09-18

- Replaced risky Unicode punctuation in runtime UI with BFA-safe ASCII characters to prevent `?` glyphs in the keystone timer and other panels.
- Removed Grievous affix alerts.
- Removed High-Powered Bolt Gun tracking and its configuration.
- Removed public-build debug commands, unknown-spell telemetry, dump UI, and debug chat output.
- Renamed the sound test command to `/bka soundpreview` and cleaned preview wording.
- Added addon version exchange and a once-per-session update notice when a newer BFA Key Alerts version is detected in the group.
- Added public release metadata and repository documentation.
