# BFA Season 1 Boss Assist Audit — v1.3.7

This layer upgrades boss abilities that were previously imported as generic INFO/TARGETED warnings into actionable high-key callouts. Research basis: pinned BFA LittleWigs boss modules plus BFA dungeon strategy guides. Geometry remains separate from strategy wording so AOE = circle, FRONTAL/CLEAVE = square, and cast control can still overlay KICK/CC.
